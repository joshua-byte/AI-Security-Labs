# AI Security Labs

Hands-on labs and experiments for a better understanding of AI system security

## Areas of Focus

- **RAG Security:** Retrieval-Augmented Generation security, corpus poisoning, retrieval manipulation, and mitigation techniques.
- **LLM Application Security:** Prompt injection, insecure handling of model inputs, and trust boundaries in LLM applications.
- **AI Agent Security:** Tool calling, excessive agency, authorization, and agent-to-API attack paths.
- **Security Testing:** Controlled experiments, reproducible test cases, result analysis, and defensive measures.

## Approach

The labs follow a practical workflow:

1. Set up a controlled test environment.
2. Introduce a specific security test or attack scenario.
3. Record and analyse the results.
4. Suggest mitigation strategies.
5. Document findings and limitations.

All experiments are intended to be reproducible and to distinguish observed results from assumptions.

## Environment
The current labs primarily use:

- Python
- Ollama for local model inference
- PortSwigger
- DVLLM (Damn Vulnerable LLM)
- Locally hosted language and embedding models
- Custom scripts for security testing and evaluation

Individual lab directories contain their own setup instructions and dependencies.
